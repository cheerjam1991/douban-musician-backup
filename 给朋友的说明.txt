豆瓣音乐人备份（不用懂代码）

适用：苹果电脑（M 系列芯片，近年的 Mac）
Windows 或 Intel 老款 Mac 用不了这个包，让朋友再跟你说。

怎么打开：
1. 解压后双击「豆瓣音乐人备份」
2. 如果提示「无法验证开发者」：按住 Control 键再点图标 → 打开 → 打开
3. 会自动弹出一个网页，操作都在这个网页里完成（不要把网页关掉）

怎么备份：
1. 点「打开豆瓣登录页」，用你自己的音乐人账号登录
2. 把小站地址贴进去，例如 https://site.douban.com/你的名字/
3. 点「自动读取登录」；若弹出钥匙串/权限，点允许
4. 点「开始备份」
5. 歌会进「下载」文件夹里的「豆瓣音乐人_xxx」
6. 完成后点「退出」

自动读取失败时：
Chrome 打开自己的小站 → 按 F12 → 点「网络」→ 刷新
→ 点最上面一条 → 找到 Cookie → 全选复制 → 粘贴到「登录信息」
